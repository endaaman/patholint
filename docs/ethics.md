# 倫理審査申請に係る情報整理

## 1. 研究概要

**研究題目:** ローカルLLMを用いた病理診断報告書の規約準拠検証システムの開発

**研究責任者:** 遠田 建（北海道大学 大学院医学研究院 連携研究センター医学研究AI支援部門（PRISM-HU）/ 腫瘍病理学教室）

**研究の目的:** 病理診断報告書が各種取扱い規約に準拠しているかをLLMで自動検証するシステムを開発し、規約ルールセットをプロンプトに含めることの検出性能への効果を定量的に評価する。修正は行わず、記載不備の検出（Validation）に責務を限定する。

## 2. データの出どころ

### 2.1 対象

- **種別:** 腫瘍病理で診断された病理診断報告書（手術検体・内視鏡検体・生検検体）
- **対象臓器:** 大腸癌をはじめ、各種取扱い規約が存在する臓器の腫瘍（胃癌、肺癌、乳癌等）を対象とする
- **収集元:** 北海道大学大学院医学研究院腫瘍病理学教室・北海道大学病院病理診断科における日常診療で作成された病理診断報告書
- **データ形式:** 完全に匿名化されたテキストデータ
- **除外基準:** 記載内容から個人が特定されうる希少症例は使用しない

### 2.2 研究に使用するデータ

研究に使用するのは以下の2要素のみ：

- `<findings>`: 所見（提出検体、組織所見、規約サマリー行）
- `<diagnosis>`: 病理組織診断名

具体例（大腸癌の場合）：

```
<findings>
【提出検体】1) 腹腔鏡下低位前方切除検体 直腸上部に 1/3 周性、24×20 mm 大の
  2 型腫瘍を認めます。PM 58 mm、DM 15 mm。 2) リンパ節
【組織所見】Adenocarcinoma, tub2>tub1。腫瘍は漿膜下層に浸潤している
 （pT3（SS））。リンパ管侵襲が認められます（D2-40）。
【大腸癌取扱い規約第9版】
  腹腔鏡下低位前方切除術, Ra, Type 2, 24x20 mm, tub2>tub1,
  pT3 (SS), INFb, Ly1a(D2-40), V0(E-Ma), BD2, Pn1a,
  pPM0(58mm), pDM0(15mm), pRM0, pN1a(1/9), pStage IIIa, pR0, pCurA.
</findings>
<diagnosis>Rectum, laparoscopic low-anterior resection: Adenocarcinoma.</diagnosis>
```

このように、組織所見は組織型・浸潤深度・脈管侵襲等の形態学的記述、規約サマリーは規約に基づく分類コードの羅列であり、いずれも個人を特定する情報を含まない。

以下の情報は研究データに**含まれない**：
- 患者氏名・生年月日・住所等の個人識別情報
- 病理番号・施設名・医師名・日付等のメタデータ

### 2.3 匿名性の評価

報告書の所見本文は以下の理由から個人の特定は不可能：
- 患者識別情報を一切含まない
- 記載内容は「腫瘍は漿膜下層に浸潤している」「管状腺管を形成しながら増殖」のような形態学的記述であり、個人に固有の情報ではない
- 対象は有病率の高い一般的な腫瘍であり、類似の所見パターンが多数存在する
- 腫瘍径・深達度・組織型等の数値・分類情報のみでは個人を同定できない
- 個人が特定されうる希少症例は対象から除外する
- 研究用の連番IDで管理し、元データとの対応関係は存在しない

## 4. 研究方法

### 4.1 データセット作成

1. 病理報告書をベースとし、各症例に**人為的にエラーを1件埋め込む**
2. エラーは4分類（RuleViolation、Deficiency、Inconsistency、Typo）に排他的に分類
3. 正答ラベル（Gold Standard）を付与
4. 症例数は臓器あたり50例を目安とし、最大200例程度まで拡張しうる
   - **50例の根拠:** 全体Sensitivityの条件間差（Δ≥0.20）をMcNemar検定で検出するのに十分な検出力（~80%）を確保できる
   - **最大200例の根拠:** エラー分類別（RuleViolation/Deficiency/Inconsistency/Typo）の層別分析において、各カテゴリ50例程度を確保し統計的に有意な比較を可能にするため

### 4.2 実験条件

- **Zeroshot条件:** 検出指示のみのプロンプトで報告書本文をLLMに入力
- **Ruleset条件:** 検出指示＋対象臓器の取扱い規約から作成した圧縮ルールセットを含むプロンプトで入力
- 使用するLLMモデルは固定せず、オンライン（API）・オフライン（ローカル）を問わず評価対象とする
- 現時点で使用したモデル: Claude Opus 4.6, Claude Sonnet 4.6, DeepSeek V3.2, GPT-OSS 120B, GPT-OSS 20B, SIP3-JMed 13B

### 4.3 LLM処理環境

| 環境 | モデル（現時点） | データの送信先 |
|---|---|---|
| Anthropic API | Claude Opus/Sonnet | Anthropic社クラウド（米国） |
| ローカルサーバ（H200×8） | DeepSeek V3.2 | 学内オンプレミス |
| ローカルサーバ（NVIDIA GB10） | GPT-OSS 120B/20B, SIP3-JMed | 学内オンプレミス |

- APIモデルに送信されるのは匿名化済みの所見本文のみ（メタデータは送信しない）
- ローカルモデルは学内ネットワーク内で完結
- 今後モデルの追加・変更がありうる

### 4.4 評価方法

- LLMの出力と正答ラベルを人手で照合し、TP-Exact / TP-Content / FN / FP-Relevant / FP-Spurious に分類
- Sensitivity、FP率等を算出しモデル間・条件間で比較

## 5. 該当する倫理指針

### 5.1 「人を対象とする生命科学・医学系研究に関する倫理指針」との関係

- 本研究は既存の診療情報（病理報告書テキスト）を利用する**観察研究**に該当
- 患者への侵襲・介入は一切なし
- 研究結果が個別の患者の診療に影響することはない（検証システムの性能評価が目的）

### 5.2 インフォームドコンセント

- 完全に匿名化された情報のみを使用しており、個人の特定は不可能
- 匿名加工情報のみを扱う場合は、倫理指針上の同意取得義務が軽減される可能性あり
- 具体的な対応は倫理委員会の判断に従う

### 5.3 データの管理

- 研究データは研究責任者の管理するローカル環境に保存
- 外部クラウド（Anthropic API）に送信するデータは匿名化済み所見本文のみ
